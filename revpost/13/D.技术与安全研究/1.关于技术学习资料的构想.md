## 计算机通识与高阶技能大纲

**【宗旨】：提供必要的体系**
*(打破黑盒认知，建立完整的计算机心智模型)*

### 第一部分：理论基础 (A)
*本部分从文件、硬件到系统启动，构建计算机底层运作的理论骨架。*

#### 第一章、文件系统 *(数字世界的基础秩序)*

1. **树状结构**：目录层级概念。
   - 补充：快捷方式的底层实现——Linux 的 `ln` 命令与 Windows 的 `mklink` 命令
   - 绝对路径与相对路径
2. **工作目录**：当前执行环境（Working Directory）的概念
3. **环境变量与 PATH**：系统如何找到你想运行的程序
4. **常见文件后缀**：Windows 与 Unix-like（如 Linux/macOS）系统在后缀名识别上的差异
5. **文件扩展名与属性**：扩展名只是表象，如何查看文件的真实属性（如 Magic Number）
6. **权限系统入门**：理解 Unix 哲学“一切皆文件”究竟指什么；读（r）、写（w）、执行（x）权限基础

#### 第二章、计算机硬件与操作系统 *(物理载体)*

1. **CPU（中央处理器）**：计算机的大脑
2. **内存（RAM 与 ROM）**：运行内存（RAM）与只读存储器/固件（ROM）的区别
3. **GPU 与 NPU**：图形处理器与新兴的神经网络处理器
4. **硬盘**：数据持久化存储介质
5. **网卡与声卡**：网络通信与音频处理组件
6. **主板与装机**：所有组件的连接枢纽与基础装机逻辑

#### 第三章、操作系统及其启动 *(从通电到接管)*

1. **底层引导**：主板、ROM、Bootloader 与 BIOS（以及如何进行固件更新）
2. **现代引导与恢复**：UEFI 的作用，以及 Recovery（恢复模式）是什么？
3. **系统启动流程**：开机过程详解
   - 侧注补充：启动过程中常见的软硬件兼容性问题
4. **驱动程序**：什么是驱动？显卡、声卡、网卡驱动的作用
   - 补充 Bonus：外设物理连接的基础——数据线与充电线的引脚/协议区别

### 第二部分：应用与操作使用 (B)
*本部分聚焦人机交互，理解我们日常使用的网页、图形界面和命令行背后的逻辑。*

#### 第一章、网页浏览 *(网络化的文件系统)*

1. **URL 解析**：将其视为文件系统的网络延伸。拆解协议（HTTP/HTTPS）、路由（域名/IP）与参数
2. **前端渲染机制**：浏览器如何利用 HTML、CSS、JS 呈现页面（理解相对路径在网页文件加载中的应用）
3. **交互与动态页面**：参数传递逻辑，以及 PHP 等后端语言如何生成“可变的文件”

#### 第二章、图形界面（GUI）使用
*核心思路：从 UI 设计逻辑反推软件的高效使用方法。*

1. **界面元素解构**：导航栏、侧边栏、展开项、列表、下拉菜单的交互预期
2. **状态与动作**：理解软件当前状态，复选框的作用，以及同类操作协议（如何组合动作提升效率）
3. **文本编辑工具**：富文本编辑（如 Word）与纯文本编辑（如代码编辑器）的本质区别与适用场景

#### 第三章、终端（CLI）入门

1. **Bash 命令行基础**：剖析命令语句的结构——主命令、子命令、选项（标志）与参数
2. **操作与效率技巧**：如使用 `Alt` 键在单词间快速跳转、将文件/文件夹拖入终端窗口自动生成路径等快捷操作

### 第三部分：互相独立的小专题 (C)
*本部分为进阶技能树，涵盖编程、网络、刷机、信息安全等极客专属领域。*

1. **专题一、简单程序设计与阅读**
   - 以 JavaScript (JS) 为例，了解编程基础逻辑（需结合实际代码自补充）
2. **专题二、网络传输：审查与应对**
   - 网络底层原理：OSI 五层网络模型简介
   - 应对策略：参看后续的“代理进阶”专题
3. **专题三、信息分析入门**
   - **元数据（Metadata）**：是什么？如何导致隐私泄露？无迹寻踪与搜索技巧
   - **溯源与安全**：常见网络溯源方法，网页漏洞基础，如何阅读安全白皮书
   - **语义分析**：数据与文本语义分析入门
4. **专题四、网络代理与科学上网**
   - 梯子（Proxy）的挑选逻辑与网络路由路线配置
5. **专题五、设备刷机与系统定制（Android/设备魔改）**
   - **核心概念**：解锁 Bootloader (BL)、线刷（通常针对底层/救砖）、卡刷（通常针对 ROM）、刷回官方、第三方 Recovery（如 TWRP）
   - **固件获取**：寻找官方固件，识别准确的 Product Name（产品代号）
   - **系统选择**：第三方 OS（如 LineageOS 等）的挑选指南
6. **专题六、命令行进阶**
   - Linux 终端与 Windows 命令行常见命令
7. **专题七、Markdown 语法介绍**
   - 高效的结构化纯文本写作标记语言
8. **专题八、通信协议与电子邮件**
   - 去中心化通讯协议（如 XMPP）的使用，以及电子邮件系统的底层运作逻辑
9. **专题九、浏览器拓展与系统模块**
   - 用户脚本（如 Tampermonkey 油猴插件）、浏览器扩展的使用
   - Android 系统级模块化定制：Magisk（面具）与 Lsposed 框架
10. **专题十、包管理与代码依赖**
    - 了解 `npm` (Node.js) 与 `pypi` (Python) 包管理器，处理代码依赖树与常见的环境兼容性问题
11. **专题十一、高级搜索技巧**
    - 突破普通搜索限制：使用搜索引擎高级语法（如 `site:`, `filetype:`）、寻找站内索引及挖掘互联网额外隐藏内容
12. **专题十二、AI 模型与驾驭工程**
    - 现代生成式 AI 工具的高效 Prompt（提示词）技巧与应用场景。驾驭工程
